# 抖店运营自动化脚本

用于抖店商品管理页面的两套独立用户脚本，支持 ScriptCat / Tampermonkey。

| 工具 | 功能 | 安装和使用说明 |
| --- | --- | --- |
| 价格调整自动化 | 从表格导入目标标价，预检匹配后改价并回读验证 | [价格调整说明](价格调整自动化/README.md) |
| 库存调整自动化 | 对匹配的 SKU 清零库存或添加现货库存，保存后回读验证 | [库存调整说明](库存调整自动化/README.md) |

## 安装

进入对应目录，将 `.user.js` 文件的全部内容复制到用户脚本扩展中新建的脚本中并保存，然后刷新抖店商品管理页面。具体输入格式、操作步骤和支持范围见各工具说明。

## 开发

在对应工具目录运行：

```sh
npm ci
npm test
npm run build
```

源码位于各工具的 `src/`，测试位于 `tests/`，构建入口为 `build.cjs`。仓库同时保留构建后的 `.user.js` 安装文件。

本地测试使用模拟页面，不等同于真实店铺保存验收。请依据各工具说明核对预检结果后执行，不要同时运行两个工具。

仓库不包含本地运行输出、实际导入数据、依赖目录或登录凭据。
