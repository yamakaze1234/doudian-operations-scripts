# 抖店标价调整自动化

独立的 ScriptCat / Tampermonkey 用户脚本。入口为 **商品管理 → 售卖中 → 对应商品“价格”旁的编辑图标**。将表格“售价”写入弹窗“价格”栏，即标价；到手价可能受活动影响，不修改到手价。

## 安装

在 ScriptCat 或 Tampermonkey 新建普通用户脚本，用本目录 `抖店标价调整自动化.user.js` 全文替换模板并保存。回到商品管理页按 F5，左下角出现“标价调整自动化”，位于库存工具上方。后续更新也需替换已安装脚本并刷新。

## 输入

推荐从 Excel 复制带表头的数据，必须含 `SPU`、`简称`、`售价`，建议同时含 `SKU`（真实 SKU ID）。可以带“可销”等额外列，它们不参与改价。不包含商品分组标题或合计行。

```text
SPU	SKU	简称	售价
3795722043610234968	3705468991113730	配置1：14600KF+无卡+32G+1T丨进阶版	6599
```

无表头支持固定四列 `SPU / SKU / 简称 / 售价`，或三列 `SPU / 简称 / 售价`。在 Excel 中按实际单元格复制，以上示例用制表符分隔。SPU 和 SKU 必须是文本格式的完整数字，科学计数法或已舍入的 ID 无法恢复。

提供 SKU ID 时，用 ID 定位并核对完整简称；名称不一致不会降级猜测。没有 SKU ID 时，按完整名称唯一匹配。只统一空白、全半角、大小写和竖线，不把不同型号或容量当成同一配置。

标价必须大于零，最多两位小数，不接受公式、负数、科学计数法。重复目标同价去重，冲突价格会报错或标记并跳过。

## 操作

1. 在目标店铺进入商品管理，完成或取消已有的编辑窗口。
2. 打开“标价调整自动化”，粘贴表格，点击“预检匹配”。脚本会切换售卖中并重置列表筛选，按商品扫描完整价格表，再关闭弹窗；预检不保存。
3. 核对店铺、SPU、SKU ID、简称、原标价、新标价和变动金额。异常项目显示原因并跳过。
4. 勾选核对框，点击“执行改价并保存”。工具重新核对数据，只写命中的标价；保存后重新打开，扫描完整列表，核验目标标价和非目标标价、商家编码、SKU 状态。
5. 导出 JSON 结果。只有“已验证改价”表示保存后回读通过；原标价相同的商品不会重复提交。

## 使用边界

支持本次实查的单列“配置”虚拟价格表，需有“价格、SKUID、商家编码、SKU状态”列。自动完整滚动扫描，不能用 DOM 行 key 代替真实 SKU ID。未知布局、滚动停滞、漏行、重复异常或中途数据变化停止。

操作期间不要与库存工具同时运行，也不要在同一页手工切店或修改表格。停止不会撤销已经提交的保存。保存超时或回读不一致时会标为“保存结果待核实”，不自动重试；核实后台实际标价并关闭窗口后再重新预检。若保留了未保存输入，需自行核对后取消或保存。

数据仅保存在当前页面内存，刷新前导出；脚本不连接外部服务，不打包账号或登录凭据。开发验证不提交真实标价调整。
